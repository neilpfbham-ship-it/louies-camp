# Louie's Camp

GCSE revision for Geography (Edexcel B) and English Language and Literature (AQA), built for Eddie.

Everything is in `index.html`. No build step, server or account is needed.

## Hosting on GitHub Pages
1. Upload every file in this folder to the top level of a GitHub repository.
2. In the repository, go to **Settings → Pages**.
3. Under "Build and deployment", set Source to **Deploy from a branch**, choose **main** and **/(root)**, then **Save**.
4. After a minute or two the site appears at `https://<your-username>.github.io/<repository-name>/`.

## Updating
Replace `index.html` with the new version. Eddie's progress is stored in his browser, so it is not affected.

## Progress
Progress is saved in the browser on each device. Use **Guide → Progress code** to back it up or move it to another device.
On iPhone or iPad, open the site in Safari, tap Share, then **Add to Home Screen**. It then opens like an app, and Safari is less likely to clear its saved data.
